# EMG MVP Vertical Slice v0.1

## الهدف

اختبار دورة حقيقية كاملة على مشروع واحد، بدون بناء أجزاء منفصلة لا تتصل ببعضها.

## السيناريو المرجعي

### 1. تسجيل الدخول

- المستخدم يدخل باسم المستخدم وكلمة المرور.
- النظام يحدد أدواره ومشاريعه المسندة.
- المهندس يرى المشاريع المسموح بها فقط.

### 2. اختيار المشروع

- المهندس يفتح مشروعًا مسندًا إليه.
- تظهر أقسام المشروع بنفس المسميات الحالية.
- تظهر آخر الحركات والتنبيهات.

### 3. تسجيل حركة

مثال: توريد أسمنت أو توريد عمالة أو تشغيل معدة.

- اختيار القسم.
- اختيار نوع الأعمال.
- اختيار اسم المورد.
- إدخال التاريخ والوحدة والكمية والسعر.
- إدخال مقدار الأعمال السابق وخلال الفترة عند الحاجة.
- إضافة ملاحظات.
- رفع صورة الفاتورة أو التحويل أو الإثبات.
- حفظ كمسودة أو إرسال للمراجعة.

### 4. مراجعة الحركة

- مدير المشاريع يراجع المشروع والبند والتنفيذ.
- المحاسب يراجع القيمة والمورد والمستند.
- يمكن طلب تعديل أو رفض الحركة مع السبب.
- عند الاعتماد تدخل الحركة في حساب المشروع والمورد.

### 5. تسجيل الدفع

- المحاسب يفتح حساب المورد.
- يحدد المبلغ المدفوع ومصدر الدفع وطريقة الدفع.
- يربط الدفع بالحركة أو يتركه غير موزع مع سبب.
- تظهر حالة مدفوعة جزئيًا أو مدفوعة بالكامل.

### 6. كشف حساب المورد

يظهر:

```text
إجمالي الأعمال والتوريدات
- الخصومات والتسويات
= المستحق
- المدفوع
= المتبقي
```

ويظهر التفصيل حسب المشروع والقسم ونوع التوريد.

### 7. كشف الحساب النهائي

- تظهر الحركة في إجمالي القسم المناسب.
- تتحدث قيم صادر ووارد حسب مصدر الحركة.
- تظهر نسبة المكتب ودفعات المكتب حسب إعداد المشروع.
- يستطيع المحاسب ومدير المشاريع مراجعة مصدر الرقم.

## قبول السيناريو

يعتبر السيناريو ناجحًا إذا تحقق الآتي:

- المهندس لا يستطيع رؤية مشروع غير مسند إليه.
- الحركة تحفظ بنفس المسميات المطلوبة.
- الإجمالي يحسب بشكل صحيح.
- المستند مرتبط بالحركة.
- الحركة لا تدخل الحساب قبل الاعتماد.
- الدفع الجزئي يحسب المتبقي صحيحًا.
- حساب المورد يظهر حسب المشروع والقسم.
- كشف الحساب النهائي يتتبع إلى الحركة الأصلية.
- كل إجراء يظهر في سجل التدقيق.
- يمكن تصدير التفاصيل إلى Excel.

## نطاق الاختبار الأول

يتم اختيار مشروع حقيقي يحتوي على:

- حركات خاصة بأعمال الموقع.
- مورد متعدد أنواع التوريد.
- دفعة جزئية.
- مرفق واحد على الأقل.
- حركة تحتاج مراجعة أو تسوية.

بعد نجاح السيناريو يتم توسيعه إلى أعمال الحفر والخرسانات والحديد وباقي الأقسام.
