# EMG Deployment and Operations v0.1

## 1. البيئات

نستخدم ثلاث بيئات منفصلة منطقيًا:

- Development: التطوير المحلي.
- Staging: اختبار الـPilot والاعتمادات قبل الإنتاج.
- Production: التشغيل الفعلي.

لا يتم اختبار تغييرات كبيرة مباشرة على Production.

## 2. مكونات VPS البداية

- Reverse proxy.
- Frontend service.
- .NET Backend service.
- PostgreSQL.
- File storage أو volume منفصل.
- خدمة نسخ احتياطي.
- Logs وMonitoring.

يمكن في البداية تشغيلها على VPS واحد مع فصلها منطقيًا، ثم نقل PostgreSQL والتخزين إلى خدمات مستقلة عند زيادة الاستخدام.

## 3. النطاق والحماية

- HTTPS إجباري.
- مفاتيح وأسرار خارج الكود.
- Firewall.
- إغلاق المنافذ غير اللازمة.
- PostgreSQL غير مكشوف للعامة.
- حسابات تشغيل بصلاحيات أقل ما يمكن.
- تحديثات أمنية دورية.
- تحديد حجم وأنواع الملفات المرفوعة.

## 4. النسخ الاحتياطي

يتم الاحتفاظ بنسخ من:

- قاعدة البيانات.
- المرفقات.
- إعدادات التشغيل.
- ملفات الترحيل والتقارير المهمة.

يجب اختبار استعادة نسخة احتياطية دوريًا، لأن وجود النسخة دون اختبار استرجاع لا يضمن صلاحيتها.

## 5. النشر

ترتيب النشر:

```text
اختبارات
→ Build
→ Deploy على Staging
→ اختبار Pilot
→ اعتماد
→ Deploy على Production
```

كل إصدار يحمل رقمًا واضحًا ويمكن الرجوع للإصدار السابق عند وجود مشكلة.

## 6. المراقبة

نراقب:

- حالة Backend.
- اتصال قاعدة البيانات.
- مساحة التخزين.
- حجم المرفقات.
- استهلاك الذاكرة والمعالج.
- زمن استجابة الـAPI.
- الأخطاء والاستثناءات.
- فشل المهام الخلفية.
- محاولات الدخول الفاشلة.

## 7. التوسع

عند زيادة الاستخدام يمكن فصل:

- Frontend.
- Backend.
- PostgreSQL.
- File storage.
- Background workers.

يجب ألا تعتمد الواجهة أو الـBackend على ملفات محلية مؤقتة أو إعدادات خاصة بـVPS واحد.

## 8. التشغيل والإدارة

- إعداد حسابات الإدارة منفصلة عن حسابات التشغيل.
- وجود سجل للتغييرات والنشر.
- توثيق متغيرات البيئة.
- تحديد مسؤول النسخ الاحتياطي.
- تحديد مسؤول الموافقة على النشر.
- توثيق طريقة استعادة النظام.

## 9. الاستعادة عند الطوارئ

يجب أن يكون لدينا إجراء واضح لـ:

1. إيقاف استقبال التغييرات عند الحاجة.
2. تحديد آخر نسخة سليمة.
3. استعادة قاعدة البيانات.
4. استعادة المرفقات.
5. اختبار الدخول والحركات والتقارير.
6. إعادة التشغيل.
7. تسجيل الحادث والإجراء.
