# EMG Project Lifecycle v0.1

## 1. إنشاء المشروع

عند إنشاء مشروع جديد نسجل البيانات الأساسية المتاحة في ملفات المشاريع الحالية:

- اسم المشروع.
- كود أو رقم القطعة إن وجد.
- اسم العميل أو المالك.
- موقع المشروع.
- تاريخ البداية.
- حالة المشروع.
- نسبة المكتب أو الاتفاق المالي عند وجودها.
- ملاحظات عامة.

اسم المشروع يحتفظ بالصيغة التي اعتاد عليها المكتب، مثل اسم العميل أو رقم القطعة أو اسم المصنع.

## 2. أقسام المشروع

عند فتح المشروع تجهز الأقسام بنفس المسميات الموجودة في الملفات:

- خاص بأعمال الموقع.
- دفعات تحت الحساب.
- كشف حساب نهائي.
- أعمال الحفر.
- أعمال الخرسانات.
- أعمال توريد الحديد.
- أعمال المباني.
- أعمال المحارة.
- أعمال العزل.
- أعمال الكهرباء.
- أعمال السباكة.
- تقارير.
- مرفقات.

يمكن تفعيل أو إخفاء قسم حسب طبيعة المشروع، لكن لا يتم تغيير المسمى أو حذف تاريخه.

## 3. تكليف المهندسين

كل مشروع يمكن أن يرتبط بـ:

- مهندس مسؤول.
- مهندس بديل.
- أكثر من مهندس حسب الحاجة.
- مدير مشاريع متابع.

كل تكليف يحتوي على:

- المستخدم.
- المشروع.
- الدور داخل المشروع.
- تاريخ بداية التكليف.
- تاريخ نهاية التكليف.
- حالة التكليف.
- ملاحظات.

عند تبدل المهندس، ينتهي التكليف السابق ويبدأ تكليف جديد. لا تتغير ملكية الحركات القديمة.

## 4. حالات المشروع

```text
مسودة
→ نشط
→ متوقف مؤقتًا
→ تحت المراجعة النهائية
→ مغلق
```

المشروع المغلق يكون للقراءة والتقارير فقط، ولا يقبل حركات جديدة إلا بإعادة فتح مصرح بها ومسجلة السبب.

## 5. فتح التشغيل

بعد إنشاء المشروع وتكليف المهندس:

1. يتم تفعيل المشروع.
2. تظهر أقسامه للمستخدمين المسموح لهم.
3. يبدأ المهندس تسجيل الحركات.
4. تظهر الحركات للمراجعة والاعتماد.
5. تبدأ حسابات الموردين والدفعات وكشف الحساب النهائي بالتجميع.

## 6. نقل ملفات المشاريع الحالية

كل ملف Excel تاريخي يعامل كمصدر لمشروع واحد ما لم يثبت أنه يحتوي أكثر من مشروع.

أثناء النقل نحفظ:

- اسم الملف الأصلي.
- اسم الشيت الأصلي.
- رقم الصف الأصلي.
- القيمة الأصلية.
- المرفقات أو الروابط إن وجدت.
- ملاحظات الترحيل.

يتم استيراد الحركات التفصيلية وإعادة تكوين الإجماليات داخل النظام. الأرقام المجمعة أو المعادلات التي بها أخطاء لا تعتمد وحدها دون مراجعة.

## 7. إغلاق المشروع

قبل الإغلاق يجب مراجعة:

- الحركات غير المعتمدة.
- الدفعات غير الموزعة.
- حسابات الموردين.
- التسويات والخصومات.
- المرفقات الناقصة.
- صادر ووارد.
- نسبة المكتب.
- صافي المستحق للمكتب.
- كشف الحساب النهائي.

بعد اعتماد كشف الحساب النهائي يمكن إغلاق المشروع مع الاحتفاظ بكل البيانات والتاريخ.
