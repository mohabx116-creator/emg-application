# EMG UX and Navigation v0.1

## 1. المبادئ

- كل مستخدم يرى ما يخصه أولًا.
- أقل عدد ممكن من الخطوات للحركة اليومية.
- المسميات الحالية تظل كما هي.
- التفاصيل تظهر عند الحاجة ولا تثقل الشاشة الأولى.
- كل رقم مهم يمكن فتح مصدره.
- كل حالة لها لون ونص واضحان.
- النظام يعمل جيدًا على الهاتف للمهندس وعلى الشاشة الكبيرة للمحاسب والإدارة.

## 2. الشريط العلوي

يحتوي على:

- البحث الشامل.
- التنبيهات.
- اسم المستخدم والصورة.
- اختصار الملف الشخصي.
- تغيير كلمة المرور.
- تسجيل الخروج.

## 3. الصفحة الرئيسية

### مهندس الموقع

- المشاريع المسندة إليه.
- زر إضافة مصروف ميداني.
- زر استلام توريد مواد.
- زر إثبات استلام عهدة.
- زر تشغيل معدة / عمالة.
- زر مراجعة يومية الموقع.
- زر تسجيل الحضور بالموقع.
- آخر الحركات وحالاتها.
- التنبيهات المطلوبة منه.

### المحاسب

- الحركات التي تحتاج مراجعة.
- دفعات الموردين.
- الدفعات تحت الحساب غير الموزعة.
- الموردون أصحاب الأرصدة.
- المستندات الناقصة.
- اختصارات التقارير وكشف الحساب النهائي.

### مدير المشاريع

- المشاريع التابعة له.
- مراجعات المهندسين.
- الحركات المرفوضة أو المتأخرة.
- أداء المشاريع.
- الموردون والمقاولون.

### المدير العام

- ملخص كل المشاريع.
- صادر ووارد.
- صافي المستحق للمكتب.
- أعلى المشاريع تكلفة.
- التنبيهات والاستثناءات.
- الاعتمادات المطلوبة.

## 4. صفحة المشروع

كل مشروع يعرض نفس الأقسام:

- نظرة عامة.
- خاص بأعمال الموقع.
- أعمال الحفر.
- أعمال الخرسانات.
- أعمال توريد الحديد.
- أعمال المباني.
- أعمال المحارة.
- أعمال العزل.
- أعمال الكهرباء.
- أعمال السباكة.
- الموردون والمقاولون.
- دفعات تحت الحساب.
- تقارير.
- مرفقات.
- كشف حساب نهائي.

كل قسم يعرض الملخص أولًا ثم الجدول التفصيلي ثم المرفقات والتقارير المرتبطة.

## 5. صفحة المورد

تعرض:

- بيانات المورد.
- أنواع ما يورده أو ينفذه.
- المشاريع المرتبطة.
- كل الحركات.
- إجمالي المستحق.
- إجمالي المدفوع.
- المتبقي.
- الدفعات الجزئية.
- التسويات والخصومات.
- كشف الحساب القابل للتصدير.

## 6. صفحة الحركة

تعرض في أعلى الصفحة:

- المشروع.
- القسم.
- نوع الحركة.
- المورد.
- التاريخ.
- الحالة.
- الإجمالي.

ثم:

- تفاصيل الكمية والوحدة والسعر.
- المرفقات.
- الدفعات المرتبطة.
- سجل الاعتماد.
- الملاحظات.

## 7. البحث الشامل

يظهر من أي شاشة، ويبحث في:

- اسم المشروع.
- اسم المورد.
- رقم الحركة.
- رقم الفاتورة أو التحويل.
- الوصف.
- الملاحظات.
- المرفقات.

مع فلاتر المشروع والقسم والحالة والفترة والمستخدم.

## 8. التفاعل والوضوح

- زر الإجراء الرئيسي ظاهر وواضح.
- النماذج تقسم إلى خطوات قصيرة عند الحاجة.
- الأخطاء تظهر بجانب الحقل وبعبارة مفهومة.
- يتم حفظ المسودة تلقائيًا عند الإمكان.
- تظهر رسالة نجاح بعد الحفظ أو الإرسال.
- العمليات الحساسة تحتاج تأكيدًا.
- الشاشات الفارغة تعرض الإجراء المناسب بدل ترك المستخدم أمام صفحة بيضاء.
- آخر استخدامات المستخدم تقترح المشروع والمورد والوحدة عند الحاجة.
