# EMG Implementation Roadmap v0.1

## المرحلة 0: تثبيت الأساس

- اعتماد وثائق الـConcept والبيانات والصلاحيات.
- اعتماد المسميات النهائية.
- اختيار نسخة Berry النهائية.
- تحديد المشروع التجريبي.
- تحديد قواعد الاعتماد وحدود الصلاحيات.
- تجهيز المستودعات المنفصلة.

## المرحلة 1: النسخة التشغيلية الأولى

### Authentication وUsers

- تسجيل الدخول.
- المستخدمون والأدوار المتعددة.
- تكليف المستخدم بالمشاريع.
- الملف الشخصي.
- تغيير واسترداد كلمة المرور.

### المشاريع

- إنشاء المشروع.
- حالات المشروع.
- الأقسام بنفس مسميات الشيتات.
- تكليف المهندس.

### التشغيل اليومي

- خاص بأعمال الموقع.
- أعمال الحفر.
- أعمال الخرسانات.
- أعمال توريد الحديد.
- المرفقات.
- مراجعة يومية الموقع.
- تسجيل الحضور بالموقع.

### الموردون والمقاولون

- قائمة الموردين.
- أنواع التوريد المتعددة.
- حساب المورد.
- التوريدات والمستحقات.
- الدفعات الجزئية والكاملة.
- الخصومات والتسويات.

### الرقابة المالية

- دفعات تحت الحساب داخل الرقابة المالية.
- توزيع الدفعات.
- كشف حساب المورد.
- كشف الحساب النهائي.
- التقارير الأساسية وتصدير Excel.

## المرحلة 2: التوسع التشغيلي

- أعمال المباني.
- أعمال المحارة.
- أعمال العزل.
- أعمال الكهرباء.
- أعمال السباكة.
- إدارة المعدات بصورة أوسع.
- تقارير مقارنة وتكلفة أكثر تفصيلًا.
- تنبيهات متقدمة.
- استيراد باقي المشاريع.

## المرحلة 3: التحسين والتوسع

- PWA أو تطبيق موبايل.
- إشعارات Push أو بريد.
- معالجة ملفات جماعية.
- تقارير إدارية متقدمة.
- تكاملات مالية مستقبلية.
- دعم شركة أخرى عند الحاجة.

## ترتيب التنفيذ داخل كل ميزة

```text
قاعدة البيانات
→ Business Rules
→ API
→ صلاحيات واعتماد
→ واجهة المستخدم
→ اختبار
→ تقرير وتصدير
```

## Definition of Done

لا تعتبر الميزة مكتملة إلا إذا:

- تعمل بالصلاحيات الصحيحة.
- تحفظ البيانات مترابطة.
- تمنع القيم غير الصحيحة الأساسية.
- تسجل المرفقات وسجل التدقيق.
- تظهر في التقارير المرتبطة.
- تم اختبار الحالات العادية والاستثنائية.
- تعمل على الهاتف إذا كانت موجهة للمهندس.
- لا تكسر المسميات أو طرق الحساب المعتمدة.
