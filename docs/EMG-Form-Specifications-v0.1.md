# EMG Form Specifications v0.1

## 1. الحقول المشتركة للحركات

كل حركة تحتوي عند الحاجة على:

- المشروع.
- القسم.
- التاريخ.
- نوع الأعمال.
- اسم المورد.
- الوحدة.
- السعر بالجنيه.
- الكمية أو مقدار الأعمال.
- ملاحظات.
- المرفقات.
- طريقة الدفع.
- مصدر الدفع.
- حالة الحركة.

## 2. خاص بأعمال الموقع

- رقم البند.
- التاريخ.
- نوع الأعمال.
- اسم المورد.
- الوحدة.
- السعر بالجنيه.
- مقدار الأعمال السابق.
- خلال الفترة.
- مجموع مقدار الأعمال.
- إجمالي تكلفة العمل.
- ملاحظات.

الحساب الافتراضي:

```text
مجموع مقدار الأعمال = السابق + خلال الفترة
إجمالي تكلفة العمل = مجموع مقدار الأعمال × السعر بالجنيه
```

## 3. أعمال الحفر

### كمية مباشرة

- الوصف.
- الوحدة.
- الكمية.
- السعر.
- الإجمالي.

### أبعاد

- الطول.
- العرض.
- الارتفاع.
- الكمية بالمتر المكعب.
- السعر.
- تكلفة النقل.
- الإجمالي.

### معدات

- نوع المعدة.
- المورد.
- ساعات أو أيام أو نقلات.
- سعر الوحدة.
- الإجمالي.

## 4. أعمال الخرسانات

### توريد الخرسانة

- وصف الخرسانة.
- المحطة أو المورد.
- الكمية.
- السعر.
- الإجمالي.
- الفاتورة.
- الدفعات.
- المتبقي.

### مصنعية الخرسانة

- وصف المصنعية.
- المقاول.
- الكمية.
- الفئة.
- الإجمالي.
- الدفعات.
- المتبقي.

## 5. أعمال توريد الحديد

- المورد.
- التاريخ.
- مقاس الحديد.
- الوزن بالطن.
- سعر الطن.
- الإجمالي.
- الدفعات.
- المتبقي.
- رقم الفاتورة.
- مرفقات التوريد والدفع.

## 6. أعمال المباني والمحارة والعزل والكهرباء والسباكة

- نوع الأعمال.
- المورد أو المقاول.
- الوحدة.
- السعر.
- مقدار الأعمال السابق.
- خلال الفترة.
- مجموع مقدار الأعمال.
- إجمالي تكلفة العمل.
- الدفعات.
- المتبقي.
- الخصومات والتسويات.
- الملاحظات والمرفقات.

## 7. إضافة مورد

- الاسم كما سيظهر.
- الاسم الأصلي من المصدر عند الترحيل.
- نوع أو أنواع التوريد.
- الهاتف.
- العنوان.
- بيانات الدفع عند الحاجة.
- المرفقات.
- الملاحظات.

## 8. دفعات تحت الحساب

- العميل أو المالك.
- الدافع الفعلي.
- المستلم الفعلي.
- المشروع أو المشاريع.
- المبلغ.
- التاريخ.
- طريقة الدفع.
- رقم التحويل أو الشيك.
- المرفق.
- التوزيع على الأقسام أو الموردين أو المكتب.
- غير الموزع.
- ملاحظات.

## 9. تسجيل الحضور بالموقع

- المستخدم.
- المشروع عند الحاجة.
- التاريخ.
- وقت الحضور.
- وقت الانصراف.
- الملاحظات.

يظهر طلب تسجيل الحضور عند فتح التطبيق أو تسجيل الدخول.

- المصروفات.
- المعدات والعمالة.
- المستجدات.
