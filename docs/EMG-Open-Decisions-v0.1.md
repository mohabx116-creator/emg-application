# EMG Open Decisions v0.1

هذه النقاط هي القرارات المتبقية قبل بدء التنفيذ. لا يتم افتراضها من ملفات Excel إذا لم تكن مثبتة بوضوح.

## 1. نسخة Berry — معتمد

تم اعتماد نسخة React + Vite الموجودة حاليًا في المشروع.

## 2. استرداد كلمة المرور — معتمد

مسؤول المنظومة يستطيع عمل Reset من لوحة إدارة المستخدمين. تعود كلمة المرور إلى قيمة افتراضية أو مؤقتة، مع إجبار المستخدم على تغييرها عند أول دخول بعد الـReset.

## 3. حدود الاعتماد — مرنة

قواعد الاعتماد قابلة للضبط من مسؤول المنظومة حسب نوع الحركة وقيمتها والمشروع، دون تثبيت حدود مالية داخل الكود.

## 4. نصيب المكتب — معتمد مبدئيًا

المكتب يحصل على نسبة من الإجمالي المعتمد للمشروع أو الإجمالي الداخل للمشروع حسب الأساس المعتمد لكل مشروع. تكون النسبة وأساسها إعدادين مرنين، مع مقارنة كل مشروع بالداتا التاريخية قبل اعتماد الترحيل.

```text
الإجمالي المعتمد للمشروع × نسبة المكتب = نصيب المكتب
نصيب المكتب - دفعات المكتب = صافي المستحق للمكتب
```

## 5. العميل والمالك والدافع — مرن

تظل هذه أطرافًا يمكن أن تكون منفصلة أو نفس الطرف حسب المشروع والداتا. لا يتم افتراض أنها كيان واحد دائمًا.

## 6. الحضور — معتمد مبدئيًا

كل مستخدم يسجل الدخول أو يفتح التطبيق تظهر له مطالبة تسجيل الحضور. الحضور مرتبط بالمستخدم واليوم، ويمكن ربطه بالمشروع عند الحاجة حسب صلاحية المستخدم.

## 7. العملات — معتمد

الجنيه المصري فقط في النسخة الأولى.

## 8. المرفقات — يحددها النظام

يتم وضع حدود آمنة لحجم الملف ونوعه، مع دعم الصور وPDF وملفات Excel والمستندات الشائعة، وتخزينها بشكل منظم مرتبط بالمشروع أو الحركة.

## 9. الترحيل — صلاحية قابلة للمنح

استيراد وترحيل ملفات Excel يكون صلاحية مستقلة يمكن منحها لأي مستخدم مناسب. نتيجة الترحيل تظل تحت المراجعة حتى اعتمادها.

## 10. الإشعارات — معتمد

النسخة الأولى تستخدم إشعارات داخل النظام فقط، مع قابلية إضافة البريد أو Push مستقبلًا.

## قاعدة التعامل مع القرارات

كل قرار يتم اعتماده يضاف إلى وثائق الـConcept والـArchitecture والـWorkflow، ولا يبقى اتفاقًا شفهيًا منفصلًا عن المستندات.
