# EMG Migration and Data Quality v0.1

## 1. الهدف

نقل ملفات المشاريع الحالية إلى النظام مع الحفاظ على تفاصيلها ومسمياتها، وإعادة بناء الحسابات من الحركات التفصيلية بدل الاعتماد الأعمى على الإجماليات المحفوظة في Excel.

## 2. مصدر الترحيل

كل ملف Excel يعتبر مصدرًا تاريخيًا، مع حفظ:

- اسم الملف.
- اسم الشيت.
- رقم الصف.
- القيمة الأصلية.
- المعادلة الأصلية إن وجدت.
- المرفق أو الصورة المرتبطة إن وجدت.
- ملاحظة الترحيل.

## 3. خريطة الشيتات

- خاص بأعمال الموقع ← الحركات اليومية.
- دفعات تحت الحساب ← حركات الدفعات والتوزيعات المالية.
- كشف حساب نهائي ← بيانات ومخرجات الحساب النهائي.
- أعمال الحفر ← حركات الحفر وطرق حسابها.
- أعمال الخرسانات ← توريد الخرسانة ومصنعية الخرسانة.
- أعمال توريد الحديد ← توريدات الحديد.
- أعمال المباني والمحارة والعزل والكهرباء والسباكة ← حركات الأقسام المتخصصة.
- تقارير ← تقارير تاريخية أو قوالب.
- مرفقات ← المستندات والملفات المرتبطة.

## 4. قواعد الاستيراد

- لا نعتبر الصفر دليلًا قطعيًا على عدم وجود حركة.
- لا ندمج الأسماء المتشابهة تلقائيًا.
- لا نغير المسميات الأصلية.
- لا نحول الملاحظات الحرة إلى حقائق مؤكدة دون مراجعة.
- لا نعتبر الفاتورة دليل دفع تلقائيًا.
- لا نعتبر الدفعة دليل توريد تلقائيًا.
- لا نكرر الحركة بسبب وجودها في أكثر من ملخص.
- لا نجمع صادر ووارد أو أرصدة من أنواع مختلفة دون تعريف واضح.

## 5. التطبيع المساعد

يمكن إنشاء تصنيف داخلي مساعد للتقارير دون تغيير النص الأصلي، مثل:

- باليومية وباليوميه ← تصنيف وحدة يومية.
- بالساعة وبالساعه ← تصنيف وحدة ساعة.
- بالنقلة وبالنقله ← تصنيف وحدة نقلة.
- بالجنيه وبالجنية ← تصنيف وحدة مبلغ.

القيمة الأصلية تظل محفوظة وتظهر عند الحاجة.

## 6. مشاكل يتم تعليمها للمراجعة

الحركات أو الخلايا التالية لا يتم حذفها، بل تظهر كتحذيرات:

- أخطاء `#REF!` أو `#VALUE!`.
- اختلاف السعر × الكمية عن إجمالي السطر.
- مورد غير مسجل.
- تاريخ ناقص.
- وحدة غير واضحة.
- دفعة غير موزعة.
- إجمالي لا يمكن تتبعه.
- تكرار محتمل.
- خصم أو تسوية سالبة بلا سبب واضح.

## 7. مراحل الترحيل

1. جرد الملفات والشيتات.
2. تحديد المشروع المقابل لكل ملف.
3. قراءة الحركات التفصيلية.
4. ربط الموردين والأسماء البديلة بعد المراجعة.
5. تحويل الحركات إلى الأقسام المناسبة.
6. إعادة حساب الإجماليات.
7. مقارنة النتائج بالأرقام المحفوظة في الملفات.
8. عرض الفروقات والتحذيرات.
9. اعتماد الترحيل لكل مشروع.
10. إغلاق نسخة الترحيل للقراءة فقط.

## 8. الترحيل التجريبي

قبل نقل كل الملفات، يتم اختبار العملية على مشاريع متنوعة:

- مشروع يحتوي دفعة مشتركة بين أكثر من مشروع.
- مشروع يحتوي دفعات وتحويلات متعددة.
- مشروع يحتوي خصومات وتسويات.
- مشروع يحتوي توريدات وأعمالًا متنوعة.

بعد اعتماد النتائج، يتم تعميم نفس قواعد الترحيل.

## 9. مصدر الحقيقة بعد التشغيل

أثناء الترحيل، ملف Excel هو المصدر التاريخي. بعد اعتماد الترحيل، تصبح الحركة داخل النظام هي مصدر الحقيقة التشغيلي، مع الاحتفاظ بالمرجع الأصلي للرجوع والمراجعة.
